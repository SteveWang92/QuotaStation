# Support

Start with the [README](README.md) and the [documentation](docs/), which cover what
QuotaStation does, how it is built, and where it keeps its data.

Open a feature request for an improvement, and a bug report for a problem you can reproduce
in a published build. Both templates are on the repository's
[issues page](https://github.com/SteveWang92/QuotaStation/issues). Include the version and
build shown in the settings page's Diagnostics section, and remove credentials, account
identifiers, prompts, source code, and private paths before attaching anything.

For security-sensitive matters, follow [SECURITY.md](SECURITY.md) instead of opening a public
issue.
